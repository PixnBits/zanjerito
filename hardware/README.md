# Hardware

## Screen mount

A 3D-printable mount that holds the Raspberry Pi touch display in the existing enclosure frame.

- [`prints/screen-mount.FCStd`](prints/screen-mount.FCStd) — FreeCAD source
- [`prints/screen-mount.stl`](prints/screen-mount.stl) — STL export for printing

**Note (2021):** fit is not yet print-verified, and the original enclosure frame needs some ribbing trimmed for the mount to fit.
